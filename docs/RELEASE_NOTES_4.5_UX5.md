# v4.5.0 UX5 — Smart Document Profiles

Documentation Excellence now adapts its presentation and guidance to Business
Process, SOP, Training Guide, Quick Reference and Troubleshooting Guide profiles.
Switching profile is immediate and preserves document context and reading
position.

Document Health now celebrates completed work alongside profile-aware
recommendations. Profiles define expectations only: they never edit content,
create mandatory validation or block export.

Semantic Document, Planner implementation and Word export behaviour remain
unchanged.
