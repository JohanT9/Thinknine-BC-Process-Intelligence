# Release Notes — Documentation Excellence v4.5 UX8

UX8 refines the complete consultant workflow without adding a new product area.
Document Library has clearer priority, rare technical and destructive controls
are quieter, workspace terminology is consistent and common keyboard workflows
require fewer pointer interactions.

Selection now updates existing cards rather than rebuilding the result DOM, and
search/filter/sort reuse the immutable metadata index. Focus reliably returns to
the originating document after Review. Persistence errors roll back metadata
cleanly and do not block the consultant's requested navigation.

Review, Semantic Document, Documentation Intelligence, Document Plan, screenshot
storage and Word export behavior remain unchanged. UX9 has not begun.
