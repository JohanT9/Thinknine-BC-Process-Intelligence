# v4.5.0 UX4 — Documentation Intelligence

Document Workspace now includes a calm Documentation Guidance panel. It shows
qualitative Document Health and grouped, filterable suggestions so consultants
can quickly understand what is ready and what may deserve attention.

Guidance uses positive language, existing diagnostics and Workspace Context
navigation. Selecting an item reveals the relevant document location and
prepares the corresponding Review step. It never edits content or blocks work.

Document Health intentionally uses no numeric score. Semantic Document,
Document Plan, Review persistence and Word export remain unchanged.
