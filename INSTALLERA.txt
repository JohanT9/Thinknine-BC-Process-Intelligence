THINKNINE BC PROCESS INTELLIGENCE 4.0.0

VIKTIGT: VERSION 4.0 HAR NYA NPM-BEROENDEN

1. Packa upp GITHUB_PATCH.zip i repositoryts rot.
2. Ersätt befintliga filer.
3. Kör:
   npm.cmd install
4. Kör:
   npm.cmd run ci
5. Commit och push.
6. Kör:
   npm.cmd run build
7. Öppna edge://extensions.
8. Klicka Läs in igen.

WORD-TEST

1. Öppna en avslutad session.
2. Välj Granska.
3. Välj Exportera Word.
4. Kontrollera att filen öppnas direkt i Microsoft Word.

Word-exporten använder nu biblioteket docx 9.7.1.
