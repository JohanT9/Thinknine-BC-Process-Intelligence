THINKNINE BC PROCESS INTELLIGENCE 4.0.1 CI HOTFIX

1. Packa upp CI_HOTFIX_PATCH.zip i repositoryts rot.
2. Ersätt befintliga filer.
3. Kör:
   npm.cmd install
4. Kör:
   npm.cmd run ci
5. Commit och push.
6. Kör:
   npm.cmd run build
7. Öppna edge://extensions och klicka Läs in igen.

Hotfixen ändrar bara lint-konfigurationen och versionsnumret.
Word-exporten är oförändrad.
